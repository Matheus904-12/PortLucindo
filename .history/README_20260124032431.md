# 🚀 Portfólio Profissional - Matheus Lucindo

> Desenvolvedor Full Stack Júnior @ BCR.CX | Analista de Software

## 🎯 Sobre Este Projeto

Portfólio profissional moderno e responsivo desenvolvido para apresentar meus projetos, experiências e habilidades técnicas. O site utiliza design minimalista inspirado no BASIKARA, com foco em usabilidade e performance.

## ✨ Versão 2.0 (Atual)

**🌐 Deploy Netlify:** [matheuslucindo.netlify.app](https://matheuslucindo.netlify.app)

### 🎨 Características Principais

- ✅ **Design Moderno:** Interface minimalista com tipografia ousada (Space Grotesk + Inter)
- ✅ **Cursor Customizado:** Interação visual única que muda de cor por seção
- ✅ **Animações Suaves:** Transições fluidas e efeitos parallax
- ✅ **Sistema Dinâmico:** Dados carregados via JSON (`v2/data/portfolio-data.json`)
- ✅ **Responsivo:** Mobile-first design com suporte completo a dispositivos móveis
- ✅ **Formulário de Contato:** Envio de emails via PHP integrado
- ✅ **Dados Automáticos:** Idade e copyright atualizados dinamicamente
- ✅ **Performance:** Otimizado para carregamento rápido

### 🎨 Paleta de Cores

- **Primária:** `#000000` (Preto)
- **Secundária:** `#FFFFFF` (Branco)
- **Destaque:** `#FFE500` (Amarelo vibrante)

### 📂 Estrutura do Projeto

```
v2/
├── index.html              # Página principal
├── send-email.php          # Backend para formulário de contato
├── assets/

│   ├── js/

│   └── images/            # Imagens do portfólio

```
